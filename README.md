# العالم الصغير

منصة مدرسية عربية من تسع صفحات لمدرسة الطفولة المبكرة بابتدائية عسفان. تضم معمل الرياضيات والبحث العلمي والرحلات المدرسية والفهم القرائي، مع أربع فصول ومشاركات تخضع لمراجعة المشرفة.

## تشغيل الرابط العام مجانًا

من إعدادات هذا المستودع في GitHub، افتح **Settings → Pages**. تحت **Build and deployment** اختر **Deploy from a branch**، ثم اختر الفرع **main** والمجلد **/docs** واضغط **Save**. بعد اكتمال النشر يظهر رابط الموقع في صفحة Pages، وعنوانه المعتاد:

`https://rus1999rusia-rgb.github.io/alalam-alsaghir/`

مجلد `docs/` هو النسخة الجاهزة لـ GitHub Pages. ملفات `dist/` هي النسخة الأصلية للاستضافة من جذر الموقع. عند تعديل ملفات `dist/` شغّل `node scripts/build-pages.mjs` لإعادة توليد `docs/` ثم احفظ التغييرات.

لشرح الصفحات وطريقة المشرفة والمشاركة والخصوصية، اقرأ [دليل المنصة](PLATFORM-GUIDE.md). لا تحتاج الطالبة إلى حساب.
